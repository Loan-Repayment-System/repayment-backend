# repayment-backend

가계대출 상품설명서를 바탕으로 한 대출금 상환 시스템의 백엔드 서버입니다.

## 프로젝트 소개

KB국민은행 부트캠프(KB IT's Your Life)를 수료한 뒤, 배운 기술을 실제 은행 업무에 적용해 보려고 시작한 개인 프로젝트입니다.
은행 웹사이트에 공개된 가계대출 상품설명서를 직접 분석하고, 분석한 도메인 규칙을 바탕으로 대출금 상환 시스템을 구현합니다.

### 목표

- 상품설명서의 도메인 규칙을 직접 해석해, 복잡한 도메인 로직을 근거가 추적되는 코드로 구현합니다.
- 실제 운영에서 일어날 수 있는 기술적 문제를 직접 재현하고 해결합니다.
- 여신 담당자의 업무 불편을 찾아 개선하는 맞춤형 기능을 개발합니다.

## 전체 흐름

1. **대출 개설** — 회원이 대출을 개설하면 계약, 대출 계좌, 상환 스케줄(회차)이 만들어집니다.
2. **일마감 (매일 자정)** — 기준금리 조회 → 대출 스케줄 판정(회차 금액 확정, 연체 판정) → 대출별 상태 판정 → 상태 변화에 따른 처리(연체금 부과, 기한이익상실·만기 경과 전환)를 차례로 실행합니다.
3. **상환** — 고객이 금액을 정해 상환하면, 상환 계좌에서 은행 수납 계좌로 당행 이체한 뒤 연체금 → 이자 → 원금 순서로 충당하고 대출 상태를 다시 판정합니다. 모두 한 트랜잭션입니다.
4. **완제** — 갚을 것이 남지 않으면 완제로 판정되고 일마감 대상에서 빠집니다.

## 주요 기능

### MVP

| 구분 | 기능 | 설명 |
|---|---|---|
| 온라인 | 회원가입 · 대출 개설 | 대출 계약, 대출 계좌, 상환 스케줄 생성 |
| 온라인 | 고객 상환 API | 상환 가능 확인, 당행 이체, 채무변제충당순서(연체금 → 이자 → 원금)에 따른 충당, 상태 판정 |
| 온라인 | 조회 API | 갚을 금액, 대출 · 상환 내역 조회 |
| 배치 | 일마감 배치 | 기준금리 조회(한국은행 API), 상환금 확정, 연체 판정, 연체금 부과, 기한이익상실 · 만기 경과 전환 (개인채무자보호법 반영) |

### 고도화 (MVP 이후)

| 구분 | 기능 | 설명 |
|---|---|---|
| 배치 | 자동 상환 배치 | 약정일에 상환 계좌에서 자동 상환 |
| 온라인 | 타행 이체 상환 | 외부 이체 API 연동 |
| 온라인 | 중복 요청 처리 | 같은 상환 요청에 이전 결과 반환 (멱등성) |
| 온라인 | 여신 담당자 업무 API | 여신 현황 조회, 상환 거래 취소, 연체 위험 고객 · 기한이익상실 통지 대상 조회 |
| 배치 | 현황 지표 배치 | 여신 현황 지표 집계, 원장 대사(잔액 검증), 연체 위험 고객 추출 |

## 기대 성과

1. **여신 도메인 역량** — 가계대출 상품설명서를 분석하며 금리, 상환 방법, 채무변제충당순서, 연체 규칙에 대한 도메인 지식을 쌓고, 이를 코드로 옮긴 대출금 상환 시스템을 결과물로 남깁니다.
2. **문제 해결 경험과 기록** — 운영에서 일어날 만한 문제를 재현하고 해결한 경험을 얻고, 해결 방안별 트레이드오프 비교와 검증 결과를 선택 근거와 함께 기록으로 남깁니다.
3. **실무 관점의 기능 설계 경험** — 여신 담당자(은행원)의 업무 불편을 개선한 맞춤형 기능을 통해, 사용자 관점에서 기능을 기획하고 구현한 경험을 얻습니다.

## 기술 스택

| 항목 | 선택 |
|---|---|
| 언어 | Java 17 |
| 프레임워크 | Spring Boot 3.5.16 (Web, Validation, Batch) |
| 영속성 | MyBatis (mybatis-spring-boot-starter 3.0.5) |
| DB | MySQL 8.4 (로컬은 Docker Compose) |
| 스키마 버전 관리 | Flyway (앱 기동 시 적용) |
| 빌드 | Gradle 8.14.3 |
| 테스트 | JUnit 5, AssertJ, Mockito, Spring Batch Test, Testcontainers |
| CI | GitHub Actions |

## 실행 방법

```bash
cp .env.sample .env
docker compose up -d      # 로컬 MySQL (스키마는 앱이 뜰 때 Flyway가 넣습니다)
./gradlew bootRun         # http://localhost:8080, 기본 프로필 local
./gradlew build           # 컴파일 + 테스트 + jar 패키징 (Docker 필요, Testcontainers)
```
